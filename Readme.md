# Spring Boot/Postgres Docker

## Requerimietos 
* Tener docker en la computadora instalado
* Tener SDK Java 17
* Tener postman

## Pasos para ejecucion del proyecto
1. Execute command [docker run --name some-postgres -dp 5432:5432 -e POSTGRES_PASSWORD=postgres -d postgres]
